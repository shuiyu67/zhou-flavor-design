# 舟味设计系统（明日方舟实证风格）

> 来源：知乎《从ta的视角看UI#1——明日方舟美术设计分析》（纳兹）正文 + 26 张官方截图逐张实证。
> 2026-09-24 新增：直接抓取官方线上代码实证（ak.hypergryph.com Next.js 站 + monster-siren.hypergryph.com umi 站的全部 CSS），见 §1.6。
> 经 v1 全毙教训校准：**舟味是信息设计/界面思维，不是海报思维。** 一切装饰服务于信息层级。

## 0. 核心判断标准（先背这个）

一张图有没有舟味，看五条：
1. **克制**：黑白灰低饱和基座，亮色只做小面积点睛（警戒色逻辑），绝不整面高饱和。
2. **信息设计骨架**：chip 标签、大数字+小注释、细下划线信息行、层级分明的 panel——像"界面"而不是"画"。
3. **工业质感三件套**：半调点网格 / 等高线 / 斜纹（警戒条），加少量十字、角括号、六边形记号。
4. **景深**：毛玻璃强模糊背景 + 白色浮窗、投影、前景失焦——多层 canvas，不是单层平面。
5. **字体系统**：思源黑体 Heavy **负字距**大标题 + Normal 正文 + 宋体衬线装饰行 + 等宽/外语技术字点缀。

## 1. 设计系统常量（所有主题共享，不许改）

### 1.1 色板
**基座默认浅色（纸感白/浅灰）**——官方主界面、时装页、采购中心全是白卡浅底；深色（近黑蓝 `#171B26`）只用于特定命题：干员简介卡（如海沫）、章节/主题曲页。**动手前先默认浅色，深色需要理由。**
| 角色 | 值 | 用法 |
|---|---|---|
| 基座近黑 | `#141517` `#171B26` `#1A1A1A` | 深色底/章节页 |
| 基座浅灰 | `#E9EAEC` `#ECEDE8` `#F4F5F6` | 浅色底、白 panel |
| 基座白 | `#FFFFFF` | panel、chip 底、画框 |
| 正文灰 | `#6A6F78` `#8A8F98` `#9AA0A8` | 描述文字 |
| 描边灰 | `#C9CCD1` `#DDDFE2` `#3A3E46` | 分隔线、chip 边框 |
| **品牌青（唯一大面积操作色）** | `#2FA6DE`（可微调 `#35A7CF`）；**官网代码实证值 `#18D1FF`** | 操作 panel、六边形节点、高亮 tspan；官网用法见 §1.6 |
| 警戒红 | `#E14A4A`；动画专题页实证 `#CE3030` | 小图标、进度线、徽标角标（小面积！） |
| 警戒黄 | `#F2A93B` / 半调点用 `#F2C14E` | 进度条、点网格 |
| 标签功能色 | 绿 `#8FC31F`、蓝 `#3387FB`（官网代码实证） | 仅作小标签/chip 底色，区分类别，不当装饰铺 |
| 塞壬唱片冷灰系 | `#C6C9CE` `#AEB3BE` `#E2E4E8` `#D4D8DD`（实证） | 音乐/编辑部命题的灰阶基座（比游戏 UI 灰更冷更浅） |
| 主题点缀色 | 由皮肤决定（见 §3） | 只替换青/红黄中的一部分 |

### 1.2 字体
| 用途 | 字体 | 字重/字距 |
|---|---|---|
| 大标题/代号 | 思源黑体（fallback Microsoft YaHei） | 900，**letter-spacing 负值**（大字号 -4~-8） |
| 巨型数字/拉丁展示 | **Oswald Medium**（官网代码实证：`font-size:7rem; letter-spacing:-.05em`） | 窄体、负字距、配合基线裁切（见 §1.6） |
| 正文信息 | 思源黑体 | 400，0 |
| 装饰行/引言 | 思源宋体 / Noto Serif SC（fallback SimSun） | 400，可 italic、可大 letter-spacing |
| 音乐/编辑部命题展示标题 | **思源宋体 Heavy**（塞壬唱片实证：`font-size:5.66em; letter-spacing:-.08em`） | 宋体不只是装饰——唱片/编辑设计命题直接用宋体 Heavy 当大标题 |
| 品牌拉丁字 | Times New Roman / 衬线；官方另用 **Novecento Sans Wide**（宽体怪诞，官网实证）与 **Geometos**（塞壬唱片 logo 字） | 700，宽字距（EPOQUE 式） |
| 技术字点缀 | monospace / 等宽 | **仅赛博/潮流命题**（龙门系、一拾山）——常驻静帧禁用 |
| 外语装饰字 | 俄语等西里尔 | 圆润粗大，当纹理用 |
| 古典拉丁标题 | Trajan / Old Style 类衬线 | **章节、骑士、庄重命题专用**；字距缩进、中文字重调低（官方迭代结论：骑兵与猎人 KV 换 Trajan 后协调性大增） |
| 工业伪等距 | Bender 类 | 基建/工业系统专用 |

**字体是叙事工具**（AJ 分析实证）：字型按命题/阵营分配——古典衬线=建制城邦与骑士（乌萨斯/章节图），无衬线/点阵=赛博都市（龙门），伪等距=工业设施（基建）。无叙事理由的混配 = 异物感（官方踩过的坑：EVIL TIME 用 Modern 衬线配皇室装束，被批"格格不入"）。中英混排用于装饰与异域感，是官方标志性手法。

### 1.3 底图质感（⚠️ 按场合使用，不是每图必配！v2 曾因到处叠被纠正）
- 半调点网格：`<pattern>` 圆点 r=1.2~1.8，间距 14~22，黄或灰，低透明度，小面积块状。**场合：T2 品牌KV 点缀、卡片底纹**；简历卡/地图/专题页不出现。
- 等高线：4~6 条平行波荡 path，描边灰 `#C2C4BD`。**场合：T4 纸面地图专属**。
- 斜纹/警戒条：粗条纹或 `////` 斜线组。**场合：按钮/卡片底纹（低密度），呼应工业警戒意象**；不铺满页面。
- 记号（**按实证分级，v3 严查后收紧**）：
  - ✅ 允许：细横线 + 实心菱形/圆点饰符（干员卡标题两侧实证）、细十字、菱形进度标记、小星。
  - ⚠️ 限定：六边形线框 = **仅**地图操作节点、干员卡背景水印（大而极淡 `opacity≤0.1`）；挪作通用装饰 = 科技风。
  - ❌ 禁止：四角 HUD 括号、扫描线常驻静帧、glitch、等宽字点缀（仅一拾山类潮流品牌题材可用）。
- 胶片颗粒：一般不用；仅深色收尾页可叠极淡一层（≤0.10）。动效里的扫描线/glitch 属于动效层（见 animation.md §5），静帧不常驻。
- 一张图通常 **0~1 种质感层**。全叠 = AI 味。

### 1.3b 印刷/摄影隐喻（舟味的独特来源，AJ 分析实证）
舟把 UI 做成**印刷品和照片**，不是"屏幕"：
- **相片白边**：章节主题图加粗白边框，"像打印出来的照片夹在细绳上"→ 图片元素一律可加 6~10px 白边 + 微倾。
- **Vignette 暗角**：页面四周一圈内投影（热点效应），突出中心信息；多页面复用。
- **唱片封面**：章节图+局部失焦+Color Dodge 图案水印+古典衬线 = 编辑设计感。
- **局部马赛克化**："失去同步"梗，用于加载/接入叙事的界面（有剧情理由才用）。
- 焦距控制：背景失焦凸出中心、前景边缘失焦造纵深（人像模式逻辑）。

### 1.4 面板与景深
- 白色 panel：直角或小圆角，`feDropShadow`（dy=6, stdDeviation=10, opacity 0.28~0.5）。
- 毛玻璃：背景彩色内容 `feGaussianBlur stdDeviation=20+` + 深色 overlay 0.15~0.2，中央白卡聚焦。
- 大数字 panel：超大数字（900，负字距）+ 右上小标签 + 下注小灰字。
- chevron 横幅：右端箭头切角的白色横条。

### 1.5 信息组件
- **黑 chip**：黑底白字标签（OPERATION / ATTENTION / 时代 / 星火 X2.5）。
- **白 chip**：白底黑字描边（当前选中项，如 破碎日冕 EPISODE 10）。
- **信息行**：边框小 chip 标签 + 值 + 细下划线（简历卡式）。
- **双描边路线**：黑 6px 底 + 白 3.5px 面（地图连线）。
- **六边形节点**：青色填充 + 白描边。

### 1.6 官网代码实证（2026-09-24 抓取 ak.hypergryph.com / monster-siren.hypergryph.com 全部 CSS）

以下为官方线上代码直接读出的 token，优先级高于推测：

**巨型展示字标准式**（官网首页 10+ 处复用同一套写法）：
`font-family:Oswald-Medium; font-size:7rem; letter-spacing:-.05em; height:.95em; overflow:hidden; display:flex; align-items:flex-end`
——要点：**基线裁切**（.95em 容器 + 底对齐 + 裁掉超出部分），大字"被界面裁住"的工业感来源。SVG 等效：text 放进 clipPath 或用 rect 遮罩下缘 ~5%。

**斜切纪律（重要修正）**：官方 CSS 里 skew 极少，且**只用于 2~3px 细笔画**——竖分隔线 `width:2px; transform:skewX(45deg)`、边框拼的箭头图标。**整块面板斜切不是官网手法**（那是二创/AI 味来源）。细线斜切可以，面板斜切不许。

**记号文本语言**（官网真实文案）：
- 日期：`2026 // 09 / 15`（年 `//` 月 `/` 日，等宽感数字）
- 进度：`00 // 00 / 05`、`LOADING - 0 %`、`......`
- 归属声明：`RHODES ISLAND :// PROFILE`、`HTTPS://AK.HYPERGRYPH.COM/`
——`//` 与 `://` 是官网签名记号，可用于标题旁注、页脚、进度行。

**青色 `#18D1FF` 的五种官方用法**（全部是"状态/引导"，不是装饰）：
1. hover 变色（黑字→青字）
2. 选中态：青底 + **黑字**（`color:#000; background:#18d1ff`）
3. 进度条/滚动条 drag 块（`border-radius:0`，直角！）
4. 强调左边框：`border-left:4px solid #18d1ff; padding-left:.75rem`（引用/重点块）
5. 边框三角角标（1px 青色三角贴角）
——另有分类标签底色：绿 `#8FC31F` / 蓝 `#3387FB`，仅小 chip 级别。

**动效 token（实证）**：
- 统一过渡时长 `.3s`（官网 90% 过渡都是 .3s，颜色/位移/透明度混用同一档）
- 大位移加一档 `.5s ease`（塞壬唱片）
- 减速曲线：`cubic-bezier(0,1,.5,.5)`（塞壬唱片滑块）；`clip-path` 用 `.2s linear`
- 与 animation.md 的"四档时长"一致，官网实际只用到 .2/.3/.5 三档——**档位宁少勿多**

**基座灰阶（官网实证）**：浅底 `#E8E6E3`（暖纸白）、文字/深块 `#242424` `#1D1F20`、中灰 `#585858`、浅灰 `#ABABAB` `#D2D2D2`。塞壬唱片偏冷：见 §1.1。

## 3. 皮肤机制（变化维度，只动这三样）

1. **主视觉**：T2/T3 左侧的插画位（官方是人设立绘/实拍；抽象项目用几何/粒子/剪影替代）。
2. **点缀色**：替换警戒红黄或局部青色。例：炎国→纸墨+朱印；夏活→黄绿品红；整合→红。
3. **装饰符号**：六边形（前文明/科技）、朱印（炎国）、雪花（寒武纪）等主题 icon。

**不许动的**：色板基座、字体系统、chip/panel/下划线组件、克制原则。

## 4. 反面清单（v1 全毙教训，逐条防复发）

- ✗ 整面高饱和撞色（红金/蓝绿品红大色块）→ AI 味头号来源。
- ✗ 标题正字距（letter-spacing 正值拉宽）→ 官方是负字距。
- ✗ 单层平面海报构图 → 必须有 panel 分层/模糊景深。
- ✗ 抽象粒子六边形铺满当"科技感" → 记号只做点缀。
- ✗ 霓虹发光、渐变玻璃拟物 → 官方是扁平+纸感+印刷质感。
- ✗ 均质装饰无信息层级 → 每个元素必须承担信息或引导职能。
- ✗ **科技 HUD 风（v3 教训）**：深色底默认化 + 六边形装饰 + 四角括号 + 等宽英文小字 + 扫描线——这套组合一出就是 AI 科幻味。正确做法：浅色纸感底、衬线/黑体混排、饰符只用横线菱形，深色页需命题理由。

## 5. 工作流

1. 确认主题皮肤（主视觉+点缀色+符号）。
2. 选布局模板（可多模板串成片/页序列）。
3. 从 templates/ 对应 SVG 起稿，替换文案与主视觉，守 §1 常量、§4 反面清单。
4. 静帧验收后：多张 SVG/HTML → 动效（CSS/JS 时间轴）→ headless 渲染帧序列 → ffmpeg 合成 mp4。
   - 本机注意：ffmpeg 可用（winget）；无 chrome/chromium，渲染前需安装无头浏览器（`agent-browser install` 的 Chromium 可复用）。
5. 交付前 ffmpeg 抽帧自查（黑屏/字体回退/字距）。
