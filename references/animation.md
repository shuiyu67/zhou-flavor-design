# 动效规范（同一画布的连续性）

> 重写依据（v2 动效演示被毙"太普通"后重学）：
> ① 帖子原文养成页行为清单；② 鹰角系动效解析（站酷《终末地 UI 动效简析》：克制为基、秩序为纲、空间化叙事）。
> 旧版错误：整幕切换 + 通用上浮 + 白场 wipe = PPT 幻灯片。舟的动效精髓是**永远不换画布**。

## 1. 第一原则：同一画布（Same Canvas）

帖子实证的养成页行为：升级=横移淡入、升阶=人物位移、合卡=人物位移、升技能=背景不变、
查看天赋=透明浮窗、查看职业/时装=毛玻璃弹窗、属性详情=**数值向右展开**、拖拽=直接切换干员。
玩家在复杂系统里**从未离开同一张 canvas**——这被公认为方舟交互设计的杰出示范。

→ 对宣传片/动效页的意义：**"换场"不换底**。底层场景持续存在，信息层在上面进出；
观众始终知道自己待在同一个空间。禁止整幕黑场/白场重来。

## 2. 六种标准行为（全部是"局部位移"，禁止整帧切换）

| 行为 | 做法 | 用途 |
|---|---|---|
| 横移淡入 | 新信息块自右 20~40px 滑入 + opacity，300~450ms | 信息出现 |
| 人物位移 | 主体元素在画布内挪位，腾出的空间被新信息填充 | 布局重组 |
| 背景不变 | 只有前景层替换，底层完全静止 | 焦点切换 |
| 透明浮窗 | 半透明白卡浮起，下层内容隐约可见 | 轻量详情 |
| 毛玻璃覆盖 | 背景模糊加深→白卡聚焦；关闭时模糊**消退回原样**，原内容原地未动 | 重详情 |
| 数值展开 | 数字/文本从锚点**向右展开**（width 0→auto + clip），不是淡入 | 数据强调 |

## 3. 空间化（Diegetic / 画内界面）

- 浮窗带透视阴影；分层视差 2~3 层（鼠标/陀螺仪系数 0.5% / 1% / 2%）。官方主看板：设备电量/信号/时间都进浮窗，**随陀螺仪整体移动**。
- 镜头联动：换"景"时整体透视微移（scale 1.0→1.03 + translate），UI 随镜头展开——运镜与动效绑定。
- 面板可自屏幕外滑入，暗示屏幕外还有世界（打破边界）。

## 3b. 过场转场的官方逻辑（AJ 分析实证）

- **独立系统之间 = 简单深色淡出**（不是白场！深色属于舟的世界）。
- **有逻辑联系的页面 = zoom-in / zoom-out**（关卡主题图→关卡选择，镜头推进的父子关系）。这是官方转场，优先于 wipe。
- 次级系统（签到/邮件/设置）= 在原页面上方**覆盖呼出**（毛玻璃/浮窗），不离场。
- 加载等待 = 插画 + 过场动画填充，减少感知等待。

## 3c. 呼吸感 = 粒子与光效，不是元素漂移（v3 修正）

官方呼吸感来源：面板右上角光线变化、管道溢出的烟雾、**飘散的尘埃与雪花**、天灾弥散光影。
- 正确：少量粒子（尘埃光斑）缓慢飘动，**理想情况响应输入**（官方文章自己提的改进方向：拖动卡片改变尘埃轨迹）。
- 错误：让信息层元素整体漂移——信息层应近乎静止（§6 旧反面清单保留）。

## 4. 机械感缓动（全局统一，鹰角系规范）

- **全局唯一缓动**：`cubic-bezier(0.25, 0.1, 0.25, 1)`，柔和但不绵软；禁 bounce / elastic / 弧线飘动。
- **位移走直线/折线**，模拟机械导轨；面板落位可加 2~3px 一帧 overshoot（机械咬合顿挫感）。
- **全局统一时长**：微交互 200ms / 面板 350ms / 布局重组 500ms / 镜头 800ms。不许各元素各拍即合。
- 位移、展开、旋转均小幅线性；克制为基，功能性优先，拒绝无意义炫技。
- **官网实证补充（2026-09 抓取官方 CSS）**：官方线上实际只用到三档——`.2s linear`（clip-path）、`.3s`（90% 的过渡：颜色/透明度/位移统一一档）、`.5s ease`（大位移/滑块）；塞壬唱片滑块用减速曲线 `cubic-bezier(0,1,.5,.5)`。**官方连 350/800 都没有，档位宁少勿多**——自己做的片子若超出 .2/.3/.5 三档 + 镜头一档，先怀疑自己过度设计。

## 5. 动效层专属符号

黄色细线扫描、网格扫描、轻微 glitch——**属于动效层，不常驻静帧**。
（纠正记录：条纹/网格是特定场合的底图处理，见 design-system §1.3"按场合使用"；v2 曾错把它们到处叠。）

## 6. 反面清单（v2 动效演示被毙教训）

- ✗ 整幕切换 + wipe 当万能转场 → 幻灯片感，没有空间连续性
- ✗ 通用"上浮淡入"到处用 → 模板味；出现方式必须对应 §2 六种行为之一
- ✗ 呼吸漂移乱加 → 舟的静止层近乎完全静止，动的是信息层，不是氛围层
- ✗ 每帧叠扫描线/颗粒/噪点 → 纹理是调味品不是主食
- ✗ 缓动时长随手写 → 必须全局统一（§4）

## 7. 实现与渲染

- 网页端：CSS transition + JS 时间轴；`demo_animated.html` 是"同一画布"的可运行参考实现（状态机驱动局部位移，无整幕切换）。
- 成片：无头浏览器逐帧截图 → ffmpeg 合成（同 design-system §5）；动效页用 Remotion 亦可。
- 逐帧前先确认：每个动画都能归入 §2 六种行为 + §4 统一缓动时长，否则删。
