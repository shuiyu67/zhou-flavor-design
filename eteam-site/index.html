SECTION 01 // THE MODEL

Lix 模型

易腾自研中文大语言模型：从预训练到 SFT，全程国产算力，权重完整开源。

Lix（代号 小狸 / xiaoli-v2）是一个 1.465B 参数的 Llama 架构中文大语言模型。它不追求参数规模的军备竞赛，而是把每一分算力都花在中文推理能力上。
预训练 45 万步、SFT 3 亿 token，全部在中科曙光 SCNet DCU 集群上完成；SFT 语料包含 DeepSeek-R1 中文蒸馏与 GSM8K_zh 数学推理数据，共 112,580 条。
1.465B PARAMS LLAMA ARCH MIT LICENSE SCNET TRAINED
